## Swagger 추천 실습 절차

1. `GET /health`로 API 키 설정 여부를 확인합니다(실제 인증 확인은 아님).
2. `GET /perso/spaces`로 `spaceSeq`를 확인합니다.
3. `GET /perso/languages`로 언어 코드와 TTS 모델 지원을 확인합니다.
4. `GET /perso/spaces/{space_seq}/quota`로 잔여 크레딧을 확인합니다.
5. 업로드할 파일에 대해 `POST /perso/media/validate`를 선택적으로 실행합니다. **durationMs는 아래 미디어 정보표에 있는 길이를 사용**합니다.
6. `POST /perso/spaces/{space_seq}/upload/audio`에서 `stt_clean_en.wav`를 업로드하면 `mediaSeq`가 반환됩니다.
7. `PUT /perso/spaces/{space_seq}/queue`로 작업 큐를 초기화합니다.
8. `POST /perso/spaces/{space_seq}/stt?confirm_cost=true` 에서 `mediaSeq`를 입력합니다.
9. 반환된 `projectSeqList`의 번호로 `GET .../progress`를 5초 이상의 간격으로 반복 조회합니다.
10. `Completed`가 되면 `GET .../stt/script`로 결과를 확인합니다.
11. 같은 방법으로 `separation_voice_music_en.wav`와 `audio-separation` API를 연결합니다.
12. `dubbing_presentation_en.mp4`를 `upload/video`로 업로드하고 `dubbing`을 실행하여 한국어(`ko`) 또는 일본어(`ja`)로 번역합니다.
13. 더빙 프로젝트가 완료된 뒤 필요하면 `lip-sync`를 호출합니다. 삽화 영상은 실패할 수 있습니다.
14. `GET .../files`로 결과물 존재 여부를 확인한 후 `GET .../download?target=all`로 URL을 얻습니다. 반환 URL로 파일 다운로드는 별도 작업입니다.

## API 요청 예시

STT 생성 바디 (`mediaSeq`는 실제 업로드 결과로 변경):
```json
{"mediaSeq": 789, "isVideoProject": false, "title": "English STT Practice"}
```

오디오 분리 생성 바디:
```json
{"mediaSeq": 789, "isVideoProject": false, "title": "Voice Music Separation"}
```

더빙 생성 바디 (`ttsModel`은 반드시 languages 응답을 참고):
```json
{"mediaSeq": 789, "isVideoProject": true, "title": "Presentation Korean Dubbing", "sourceLanguageCode": "en", "targetLanguages": [{"languageCode": "ko", "ttsModel": "LINNET_4"}], "numberOfSpeakers": 1, "withLipSync": false, "preferredSpeedType": "GREEN"}
```
