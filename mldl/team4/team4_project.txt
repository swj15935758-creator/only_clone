AI휴먼 데일리 딥러닝 미니프로젝트 - Team 4
=======================================================

[프로젝트]
센서 이상 징후 판별

[문제 유형]
이진 분류

[핵심 모델]
RNN/LSTM

[프로젝트 설명]
20개 시점 × 3개 센서의 순차 데이터를 SimpleRNN과 LSTM으로 비교합니다.

[이번 프로젝트에서 반드시 확인할 개념]
- 3차원 순차 데이터 shape 확인
- timesteps와 features 구분
- SimpleRNN과 LSTM의 파라미터 수 비교
- 같은 학습 조건에서 두 모델의 검증 성능 비교
- EarlyStopping과 History로 과적합 여부 점검

[데이터]
- 파일명: team4_data.npz
- 수업용으로 생성한 가상 데이터입니다.
- 실제 개인정보나 민감 데이터를 포함하지 않습니다.
- 외부 다운로드 없이 바로 실습할 수 있습니다.

[필수 작업]
1. np.load()로 X와 y를 읽고 X.shape와 y.shape를 확인합니다.
2. (samples, timesteps, features)의 각 축 의미를 설명합니다.
3. SimpleRNN(24) 기반 이진 분류 모델을 만듭니다.
4. LSTM(24) 기반 이진 분류 모델을 만듭니다.
5. 두 모델은 같은 Dense 출력층, Optimizer, Epoch, Batch Size를 사용합니다.
6. binary_crossentropy와 accuracy를 사용합니다.
7. 두 모델에 동일한 EarlyStopping 조건을 적용합니다.
8. model.count_params()로 파라미터 수를 비교합니다.
9. validation loss와 validation accuracy를 비교합니다.
10. 최종 선택 모델의 혼동행렬을 그립니다.

[보고서]
`team4_report_template.md` 파일을 복사하여 결과를 작성하세요.

[필수 시각화]
- 학습곡선: train loss / validation loss
- 문제 유형에 맞는 성능 시각화
- 데이터 또는 예측 결과를 설명할 수 있는 그래프 1개 이상

[시간이 부족할 때]
1순위: 데이터 shape 이해
2순위: 모델 구성과 학습
3순위: EarlyStopping + History 확인
4순위: 최종 성능과 그래프
5순위: 보고서 결론 작성

[주의]
- Test Set을 반복적으로 보면서 모델을 수정하지 않습니다.
- StandardScaler를 사용할 때는 Training Set에만 fit합니다.
- 모델 이름보다 데이터 shape와 문제 유형에 맞는 구조를 선택하는 것이 중요합니다.
