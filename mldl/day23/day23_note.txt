## 딥러닝

1) 신경망 (Neural Network)
- 머신러닝 알고리즘 중 하나
- 인간의 뇌 기능을 흉내내서 생성함
- 입력층(Input), 은닉층(Hidden), 출력층(Outpu)으로 구성
- 층을 점점 늘려서 깊게 만든 신경망을 심층신경망(Deep Neural Network)라 함
- 깊은 층을 가진 신경망에 가중치와 편향을 학습시키는 것을 딥러닝 또는 심층학습이라 함
- 개념적으로 AI > 머신러닝 > 딥러닝

2) 신경망으로 할 수 있는 것들
- 분류
- 회귀
- 클러스터링
- 이미지생성
- 자연어처리
- 무한...

3) 관련 용어
- GPU(Graphics Processing Unit: 그래픽 처리 장치)
  그래픽 처리 장치, 고성능 병렬처리를 위한 범용 연산 장치, 수치계산에 탁월
- 셀프 수퍼바이즈러닝 (Self Supervised-Learning)
  머신러닝의 한 방법, 레이블이 없는 대규모의 데이터 셋을 사용해서 모델을 학습시키는 방법
  쉽게 말해 비지도학습
- BERT(Bidirectional Encoder Representations from Transformers)
  구글에서 개발한 자연어 처리 모델
  딥러닝의 자연어 처리분야에서 매우 중요한 시초가 되는 모델
  이전의 모델은 텍스트를 단방향으로 처리했으나 BERT 텍스트를 양방향 처리한 첫번째 모델
- 인코더(Encoder)
  자연어 처리에서 주로 사용되는 구성요소 중 하나
  주어진 입력문장을 더 의미있는 벡터 표현으로 변환하여 디코더로 전달하고
  다음 단어를 예측하거나 번역 등에 활용됨
- 퍼셉트론(Perceptron)
  인공 신경망 모델 중 하나
  다수의 신호를 받아서 하나의 신호를 출력
  뉴런의 수상돌기나 축색돌기처럼 신호를 전달하는 역할을 퍼셉트론 가중치라 함
  가중치 : 각각의 입력 신호에 부여되어 입력신호와의 계산을 한 신호의 총합으로
          정해진 임계값을 넘었을때 1을 출력
  출력 : 활성화함수((입력1*가중치1 + 입력2*가중치2 ... + 입력n*가중치n) + 편향)

 4) 딥러닝 학습 포인트
 - 데이터 : 양질의 많은 데이터
 - 모델 : CNN, RNN, FNN , Transformer ...
 - 알고리즘 : Gradient Descent(경사하강법)을 기초로 한 많은 알고리즘 ...
 - 손실함수(Loss Function) : 모델의 성능에 대한 척도로 사용하는 실제값과 예측값의 차를 구하는 함수
 - 기타 등등...

 5) 딥러닝 대표 모델
 - CNN(Convolution Neural Network)
   주로 이미지 처리에 사용되는 딥러닝 모델
   지역적인 패턴 및 공간적인 구조를 인식하기 위해서 컨볼루션레이어를 사용
   이미지의 특징을 추출하기 위해 입력데이터에 여러 필터를 적용하고
   이미지를 잘 이해할 수 있도록 설계되어 있음
 - RNN(Recurrent Neural Network)
   순차적인 데이터 처리에 사용되는 딥러닝 모델
   순환적인 구조를 가지며, 이전 시간 단계의 출력을 현재 시간 단계의 입력으로 사용
   시계열 데이터, 자연어 처리에 주로 사용
 - GAN(Generative Adversarial Network)
   생성형 모델 중 하나
   두 개의 신경망인 생성자(Generator)와 판별자(Discriminator)가 서로 대립하는 경쟁구조
   생성자는 진짜와 구별할 수 없는 가짜 데이터를 생성
   판별자는 진짜와 가짜를 더 정확하게 구별하는 일을 함
   주로 이미지 생성 / 감별 / 변환 / 편집에 사용


 ## 텐서플로우 (TensorFlow)
 - 구글에서 개발한 오픈소스 머신러닝 프레임워크
 - 그래프기반 계산, 다양한 플랫폼 지원, 높은 수준의 API를 제공
 - 딥러닝에 사용되는 Keras API를 지원

 1) 텐서 (Tensor)
 - Tensor multi dimentional array(텐서 다차원 배열)의 약어
 - 텐서플로우에서 사용하는 기본 데이터타입

 2) 변수 텐서 (Variable Tensor)
 - 가변성(Mutable) 텐서로 생성 후 내부 값 수정이 가능
 - 모델의 가중치처럼 학습 중에 업데이트 되어야하는 값들을 나타내기 위해 사용
 - tf.Variable() 클래스를 사용해서 생성 (대문자로 시작)
 - 초기값과 데이터타입을 지정할 수 있음
 - 변수텐서는 assign()메소드를 사용해서 값을 변경할 수 있음

 3) 상수 텐서 (Constant Tensor)
 - 불변성(Immutable) 텐서로 생성 후 내부 값 수정이 불가능
 - 학습 중에 변경할 수 없는 값을 표현하기 위해 사용
 - 모델의 하이퍼파라미터나 고정된 상수값을 나타내기 위해 사용
 - tf.constant() 함수를 사용해서 생성 (소문자로 시작)

 4) 넘파이 배열을 텐서 변환
 변수 = tf.convert_to_tensor(넘파이배열)

 5) 리스트를 텐서 변환
 변수 = tf.convert_to_tensor(리스트)

 6) 텐서를 넘파이 배열로 변환
 변수.numpy()

 7) 텐서플로우 주요 함수
 tf.constant() : 상수 텐서 생성
 tf.Variable() : 변수 텐서 생성
 tf.add() : 두 텐서를 더하기
 tf.matmul() : 두 텐서의 행렬 곱셈
 tf.zeros((행, 열)) : 모든 요소가 0인 텐서 생성
 tf.ones((행, 열)) :  모든 요소가 1인 텐서 생성
 tf.fill((행, 열), 값) : 모든 요소가 값인 텐서 생성

 8) 텐서 주요 속성
 - 차원(Dimension) : 배열의 축의 개수
                    스칼라(차원 0), 1차원배열(차원 1), 2차원배열(차원 2) ...
 - 크기(shape) : 각 차원의 요소 수
 - 데이터타입(datatype) : 요소의 데이터타입
 - 디바이스(device) : 텐서가 어떤 장치에서 저장/연산되는지 (CPU, GPU ...)
 - 텐서연산(operation) : 텐서 덧셈, 곱셈, 활성화함수 적용...
