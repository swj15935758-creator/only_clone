# 실습과제 ② LLM 아재퀴즈 게임

**주제:** GPT가 내는 말장난 퀴즈를 맞히는 웹 게임  
**파일:** `day51_prac2.py`

## 1. 어떤 게임을 만들까요?

GPT가 **문제·정답·힌트·해설**을 만들고, 플레이어가 정답을 입력하면 Python이 판정하는 게임입니다.

**문제 예시(설명용 가상 문제):** "조용히 하라고 말하는 가오리는?" → 정답 `쉿가오리`

- 문제는 **총 5개**, 매 문제마다 GPT가 **1개씩 생성**
- 답변 기회는 **문제당 2회**
- **첫 시도 정답 20점**, **두 번째 정답 10점**
- **힌트 사용 시 획득 점수에서 5점 차감** (최소 0점)
- 2번 틀리면 **정답과 해설 공개**, 다음 문제로 이동
- 정답은 GPT를 다시 호출하지 않고, **처음 생성한 정답과 Python 문자열 비교**
- 최고 점수는 **100점**

## 2. 설치 및 실행

1. `day51_prac2.py`와 `.env`를 **같은 폴더**에 저장
2. 패키지 설치

```powershell
python -m pip install streamlit openai python-dotenv
```

3. `.env` 생성

```dotenv
OPENAI_API_KEY=발급받은_API_키
OPENAI_MODEL=gpt-4.1-mini
```

4. 실행

```powershell
python -m streamlit run day51_prac2.py
```

5. 브라우저에서 **문제 출제하기** → 답변 입력 → **정답 제출** → 해설 확인 → **다음 문제** 순으로 진행

## 3. 꼭 테스트할 6가지

- [ ] **문제 출제하기** 클릭 시 질문이 표시됨
- [ ] JSON에 `question`, `answer`, `hint`, `explanation` 4개 값 존재
- [ ] 빈 답 입력 시 기회 차감 없음
- [ ] 띄어쓰기를 달리해도 같은 단어라면 정답 인정
- [ ] 힌트 사용 후 맞히면 5점 감점, 힌트 재사용 불가
- [ ] 2번 오답 후 정답·해설 표시, 5문제 종료 시 총점 표시

### 점수 계산 예시

| 상황 | 점수 |
|---|---:|
| 첫 번째 시도 정답 | 20점 |
| 첫 번째 시도 정답 + 힌트 사용 | 15점 |
| 두 번째 시도 정답 | 10점 |
| 두 번째 시도 정답 + 힌트 사용 | 5점 |
| 두 번 모두 오답 | 0점 |

## 4. 완료 기준

**완료 기준:** 5문제 풀이가 가능하고 정답/오답/힌트가 점수에 정확히 반영되면 성공.
