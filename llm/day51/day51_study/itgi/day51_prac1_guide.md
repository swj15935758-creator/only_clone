# 실습과제 ① LLM 끝말잇기 게임

**주제:** GPT와 번갈아 단어를 내는 웹 게임 만들기  
**파일:** `day51_prac1.py`

## 1. 어떤 게임을 만들까요?

사용자가 한글 단어를 입력하면 Python이 규칙을 검사하고 GPT가 이어질 단어를 제안하는 게임입니다.

**예시:** 사용자 `사과` → GPT `과자` → 사용자 `자동차` → GPT `차표`

- 사용자가 **먼저** 단어를 입력
- 한글 **2~5글자**만 사용
- 바로 앞 단어의 **마지막 글자**로 시작
- 한 번 사용한 단어 **재사용 금지**
- 사용자 단어 1개 통과 시 **10점**, 최대 **5턴 / 50점**
- GPT가 규칙을 어기면 **1회 재요청**, 두 번 실패하면 안내하고 점수·기록은 바꾸지 않음
- **두음법칙과 실제 사전 등재 여부는 검사하지 않음** (교육용 간단 규칙)

## 2. 설치 및 실행

1. `day51_prac1.py`와 `.env`를 **같은 폴더**에 저장
2. PyCharm 터미널 또는 PowerShell에서 패키지 설치

```powershell
python -m pip install streamlit openai python-dotenv
```

3. `.env` 파일 생성 (**실제 키를 코드에 작성하지 않음**)

```dotenv
OPENAI_API_KEY=발급받은_API_키
OPENAI_MODEL=gpt-4.1-mini
```

4. 실행

```powershell
python -m streamlit run day51_prac1.py
```

5. 표시된 브라우저 화면에서 단어를 입력하고 **제출하고 GPT와 대결** 클릭


## 3. 꼭 테스트할 6가지

- [ ] 첫 단어 `사과` 입력 → 허용
- [ ] 직전 단어 `사과` 다음 `과자` → 허용
- [ ] 직전 단어 `사과` 다음 `바나나` → 시작 글자 오류
- [ ] 이미 쓴 단어 재입력 → 중복 오류
- [ ] `A과자`, `과 자`, `과` → 형식 오류
- [ ] 5번째 사용자 단어 통과 → 최종 점수 표시

참고: GPT의 단어는 생성형 응답이므로 특정 단어가 나올 것을 전제하지 마세요.

## 4. 완료 기준

**완료 기준:** 5턴을 정상 진행해 결과가 표시되고, 잘못된 단어가 점수에 반영되지 않으면 성공.
