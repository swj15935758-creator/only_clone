# 사전학습 TTS 모델 음성 합성, 화자 특성, 운율 제어, MOS 품질 평가 # 논문 가능성 있음

1. STT & TTS
    - STT(Speech To Text): 음성 파형을 문자로 바꾸는 기술, 입력은 WAV등의 음성이며 출력은 문장(전사)
    - TTS(Text to Speech): 문장을 음성파형으로 바꾸는 기술, 입력은 문자이며 출력 MP3/WAV등의 음성(합성)
    - STT에서는 정답 문장과 비교해서 WER, CER측정
    - TTS에서는 글을 알아듣기 쉬운지(Clarity, 명료도), 사람처럼 자연스러운지(Naturalness, 자연스러움),
        목소리가 일정한지(화자 일관성)평가

2. TTS 추론과 처리 단계
    - 입력 문장 > 텍스트 정규화 > 발음 변환(G2P) > 음향 표현 예측 > 파형 합성 > MP3/WAV 등에 저장
    - 예)
        입력 문장: '10kg 상품을 배송합니다.'
        텍스트 정규화: '십 킬로그램 상품을 배송합니다.'
        발음 변환 : 글자와 실제 발음의 대응을 반영
        음향 표현 예측: 각 구간의 길이, 높낮이, 음색과 주파수 특성 등을 모델이 생성
        파형 합성: 시간에 따른 소리 진폭 값의 배열 생성
        저장: 파형을 WAV, MP3 등의 파일로 저장

3. 텍스트 정규화 (Text Normalization)
    - 문장에 포함된 숫자, 날짜, 단위, 약어, 특수문자 등을 실제로 읽기 적절한 말로 변환하는 과정
    - 예)
        10kg > 십키로그램
        3개 > 세 개
        2026/10/10 > 날짜 문맥이라면 이천이십육년 시월 십일
        010-1234-5678 > 전화번호 문맥이라면 숫자말 하나씩 읽음
        1,000원 > 화페라면 천원, 숫자라면 일콤마영영영원
    - 문맥에 따라서 동일한 문자도 발음으로 풀어내는 경우의 수가 많음(특히 한국어)
    - 문장부호에 따른 피치, 길이의 차이
        - 예) '지금 출발하세요.' 는 평서형 안내, '지금 출발하세요!!!' 강조형 안내

4. G2P와 음소
    - G2P(Grapheme to Phoneme): 철자 또는 문자 표현을 발음 단위의 시퀀스로 바꾸는 과정, 처리
    - 음소(Phoneme) : 언어에서 의미를 구분하는 최소 소리 단위
    - 비음화: 국물 > 발음 궁물
    - 유음화: 신라 > 실라
    - 구개음화: 같이 > 가치
    - 글자 하나를 항상 동일하게 읽게 되면 부자연스럽거나 잘못된 발음이 발생할 수 있음

5. 음향 모델과 보코더
    - 음향 모델: 텍스트 및 발음 정보를 이용해서 소리의 시간, 주파수 특성, 다른 중간 음향 표현을 예측하는 모델
    - Mel-spectrogram : 짧은 시간 구간별 주파수 에너지 분포를 멜 척도에 따라 나타낸 2차원 표현
                        가로축: 시간, 세로축: 멜 주파수 대역, 색/숫자: 해당 대역의 에너지 크기
                        파형 그래프는 시간에 따라 진폭이 어떻게 바뀌는 가에 대한 그래프
                        스펙트로그램은 시간마다 어떤 주파수 성분이 강한가에 대한 그래프
    - 보코더(VoCoder) : 멜 스펙트로그램 등 조건 표현으로 부터 실제 재생 가능한 파형을 합성하는 합성기
        Voice enCoder   HiFi-GAN은 대표적인 신경망 보코더

6. 화자 임베딩(Speaker Embedding)
    - 임베딩: 이미지, 문장, 음성 등 복잡한 데이터를 수치 벡터로 표현하는 방법
                또는 변환된 수치 벡터
    - 화자 임베딩: 말하는 사람의 목소리 특징을 담으려는 수치 벡터
                    예) A=[0.2, -0.1, 0.7], B=[0.8, 0.3, -0.2]
    - 두 벡터의 코사인 유사도가 높으면 해당 임베딩 공간에서 방향이 비슷하다는 뜻

7. 사전 등록 음색과 Voice Cloning
    - 사전 등록 음색: 서비스에서 제공하는 voice ID를 선택해 합성
                        사용자가 별도로 학습시킬 필요가 없는 경우가 많음(미리 학습함)
    - Voice Cloning: 대상 화자의 녹음 자료 등을 바탕으로 비슷한 음색을 재현하는 기술
                        '제공된 목소리 중 선택'과 '특정인의 목소리 특징을 재현'은 서로 다른 작업

8. Prosody, Pitch, Rate, Pause
    - 운율(Prosody): 말의 높낮이, 길이, 강세, 리듬, 쉼 등의 패턴
    - Pitch: 사람이 지각하는 소리의 높낮이
    - Rate: 말하는 속도
    - Pause: 단어나 문장 사이의 쉼

9. edge-tts
    - edge-tts: 온라인 음성 합성 서비스를 활용하는 라이브러리
                인터넷 연결이 필요
    - 주요 API)
        edge_tts.Communicate(text, voice, rate, pitch): 함성 객체
            text: 읽을 문장
            voice: 사전에 등록 음색 식별자
            rate: 말의 속도 설정 문자열
            pitch: 주파수의 피치 설정 문자열
        await communicate.save(파일명): 비동기로 온라인 합성 결과를 파일로 저장
        await edge-tts.list_voices(): 비동기로 사용 가능한 음색 목록 조회

10. 비동기 # 기다리지 않고 계속 요청 하는것
    - async: 일반적으로 함수 앞에 사용하는 키워드, 함수를 비동기 처리
            비동기 처리: 다른 처리 흐름과 벗어나서 새로운 처리 흐름에서 처리
            동기 처리: 기존 처리 흐름 상에서 새로운 처리를 이어나가는 처리
    - 일반적으로 네트워크 호출, 파일I/O 등 시간이 많이 걸리는 작업에 비동기를 사용
    - await: 비동기 처리 중에 동기 처리가 필요한 경우 사용하는 키워드
    - 예) 비동기로 처리되는 함수 내에서 B작업이 A작업의 결과를 사용한다면
        B작업과 A작업은 A작업 이후 B작업 이라는 동기 처리가 필요

11. 실험 설계와 변인 통제
    - 한 번에 여러 조건을 변경하여 실험하면 어떤 조건이 결과 차이를 만들었는지 알기 어려움
    - 한 번 실험시에 하나의 조건만 변경해서  결과 차이를 확인해 나갈 필요가 있음
    - 실험 계획
        A: 문장='분석 결과를 확인하세요.',음색=기본,rate='+0%',pitch='+0Hz'
        B: 문장='분석 결과를 확인하세요.',음색=기본,rate='-20%',pitch='+0Hz'(문장만 변경)
        D: 문장='분석 결과를 확인하세요.',음색=기본,rate='+20%',pitch='+0Hz'(rate만 변경)
        E: 문장='분석 결과를 확인하세요.',음색=기본,rate='+0%',pitch='+20Hz'(pitch만 변경)
        F: 문장='분석 결과를 확인하세요.',음색=기본,rate='+0%',pitch='-20Hz'(pitch만 변경)
    - 변인 통제: 변화되는인자(factor)를 고정과 변경으로 통제

12. 오디오 크기, 재생 길이, RTF
    - duration_sec: 생성된 음성의 재생 시간(초)
    - size_bytes: 저장 파일의 크기(바이트)
    - elapsed_sec: 함성 요청으로부터 파일 저장 완료까지 걸린 시간(초)
    - RTF(Real Time Factor): elapsed_sec / duration_sec
    - RTF < 1: 재생시간보다 소요시간이 덜 덜림
    - RTF = 0: 재생시간과 소요 시간이 같음
    - RTF > 1: 재생시간보다 소요시간이 덜 걸림

13. MOS와 평가 항목
    - MOS(Mean Opinion Score, 평균 의견 점수): 여러 사람이 음성 품질에 매긴 점수의 산술 평균
    - 예) 평가 점수[4,5,3,4] > MOS = (4+5+3+4) /4 = 4.0
    - 평가 항목
        Clarity(명료도): 말한 단어와 문장을 잘 알아들을 수 있는가?
        Naturalness(자연스러움): 사람처럼 자연스럽게 말하는가?
        Speaker Consistency(화자 일관성): 같은 음색이 안정적으로 유지되는가?
