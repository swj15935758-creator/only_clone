# 요구사항 정의서

| ID | 구분 | 기능명 | 사용자 관점 요구사항 | 우선순위 | 입력 | 처리 | 출력 | 완료 기준 | 담당 | 상태 |
|---|---|---|---|---|---|---|---|---|---|---|
| DB-01 | DB | 회원 등록 | 사용자는 닉네임으로 학습자 정보를 등록할 수 있다. | 필수 | 닉네임 | 공백 입력과 중복 닉네임을 검사하고 `users`에 저장한다. | 회원 ID, 닉네임, 등록 시각 | 정상 등록 후 UUID가 생성되고, 중복 닉네임은 거부된다. | 신의진 | 코드 구현, DB 실행 확인 필요 |
| DB-02 | DB | 기존 회원 조회 | 사용자는 등록한 닉네임으로 자신의 학습 정보를 불러올 수 있다. | 필수 | 닉네임 | `users`에서 회원을 조회한다. | 회원 ID와 닉네임 | 등록된 닉네임이면 해당 회원 ID를 반환한다. | 신의진 | 코드 구현. **비밀번호 인증 기능은 없음** |
| DB-03 | DB | 연습 문장 조회 | 사용자는 카테고리와 난이도에 맞는 연습 문장을 선택할 수 있다. | 필수 | 카테고리, 난이도 | `sentences`에서 조건에 맞는 문장을 조회한다. | 문장 ID, 한국어 문장, 영어 번역 등 | 선택한 조건에 해당하는 문장만 조회된다. | 신의진 | 코드 구현, DB 데이터 확인 필요 |
| DB-04 | DB | 연습 결과 저장 | 사용자는 연습을 마친 뒤 자신의 평가 결과를 다시 확인할 수 있어야 한다. | 필수 | 회원 ID, 문장 ID, STT 결과, WER·CER, 점수, 등급, 피드백, S/D/I 합계, STT 처리시간 | 연습 1회를 `practice_runs`의 한 행으로 저장한다. | 연습 기록 ID | 저장 후 해당 회원의 연습 기록을 조회하면 결과가 나타난다. | 신의진 | 코드·화면 호출 확인, 실제 저장 재확인 필요 |
| DB-05 | DB | 글자별 오류 저장 | 사용자는 정답과 인식 결과가 어느 글자에서 다른지 확인할 수 있어야 한다. | 필수 | 연습 기록 ID, 오류 유형, 정답 글자, 인식 글자, 글자 위치 | 치환·삭제·삽입 오류를 `error_items`에 개별 저장한다. | 저장된 오류 건수와 상세 내역 | 오류가 있는 연습의 `run_id`로 해당 글자별 오류를 조회할 수 있다. | 신의진 | 코드·화면 호출 확인, 실제 저장 재확인 필요 |
| DB-06 | DB | 학습 이력 조회 | 사용자는 자신의 이전 연습 결과를 최신순으로 확인할 수 있다. | 필수 | 회원 ID | `practice_runs`, `users`, `sentences`를 연결해 해당 회원의 기록을 조회한다. | 문장, 인식 결과, 점수, 오류율, 피드백, 연습 시각 등 | 다른 회원 기록이 섞이지 않고 자신의 기록이 최신순으로 표시된다. | 신의진 | 코드 구현, DB 조회 확인 필요 |
| DB-07 | DB | 관리자 통계 조회 | 관리자는 등록 회원 수와 전체 연습 현황을 확인할 수 있다. | 필수 | 저장된 회원·연습 데이터 | 회원 수, 연습 횟수, 평균 점수, 평균 STT 처리시간과 카테고리·난이도·문장별 연습 횟수를 집계한다. | 관리자 대시보드 지표 | 화면 수치가 DB 집계 결과와 일치한다. | 신의진(DB), 이승우(UI) | SQL·화면 연결 확인, 데이터 0건 처리 보완 필요 |
| DB-08 | DB | 회원별 현황 정렬 | 관리자는 등록일별 회원의 연습 횟수를 순서대로 확인할 수 있다. | 필수 | 회원 등록 시각, 회원별 연습 횟수 | 등록일 내림차순, 같은 등록일 안에서는 연습 횟수 내림차순으로 정렬한다. | 회원별 현황 표 | 같은 날짜의 회원이 연습 횟수 순서로 표시된다. | 신의진(DB), 이승우(UI) | **요청된 정렬 기준 미반영** |
| DB-09 | DB | 데이터 수정·삭제 | 관리자는 필요한 회원·문장·연습 기록을 관리할 수 있다. | 선택 | 수정할 값 또는 삭제할 ID | 해당 데이터 수정·삭제 SQL을 실행하고 연결된 기록의 관계를 확인한다. | 처리 결과 | 지정한 데이터만 변경되며 참조 관계가 깨지지 않는다. | 신의진 | SQL·함수 구현, 관리자 화면 연결은 별도 확인 필요 |


## 비기능 요구사항
| ID | 항목 | 요구사항 | 측정 방법 | 담당 | 상태 |
|---|---|---|---|---|---|
| NFR-DB-01 | 데이터 무결성 | 연습 기록은 존재하는 회원과 문장을 참조하고, 글자별 오류는 존재하는 연습 기록을 참조해야 한다. | 유효하지 않은 ID로 저장을 시도해 거부 여부 확인 | 신의진 | 외래 키 정의 확인, DB 실행 확인 필요 |
| NFR-DB-02 | 저장 일관성 | 연습 결과와 글자별 오류를 저장할 때 일부 저장만 성공한 상황을 확인하고 처리할 수 있어야 한다. | `error_items` 저장 실패 시 `practice_runs` 상태 확인 | 신의진 | **현재 별도 저장 호출이므로 보완 필요** |


## 변경 이력
| 날짜 | 변경 ID | 변경 내용 | 사유 | 승인 |
|---|---|---|---|---|


| 구분 | 기능 | 하는 일 |
|---|---|---|
| 학습자 | 시작·회원 식별 | 닉네임으로 기존 회원을 찾거나 새 회원을 등록합니다. 현재 닉네임만 사용하며 비밀번호 인증은 없습니다. |
| 학습자 | 홈 | 오늘 학습 횟수·평균 점수·연속 학습일을 보여주고 퀴즈를 제공합니다. |
| 학습자 | 문장 선택 | 카테고리·난이도에 따라 연습 문장을 고릅니다. |
| 학습자 | 문장 듣기 | 선택한 한국어 문장을 TTS 음성으로 들려줍니다. |
| 학습자 | 음성 입력 | 직접 녹음하거나 음성 파일을 올려 연습합니다. |
| 평가 | STT·문장 비교 | 음성을 글자로 바꾸고 정답과 비교해 WER·CER, 점수, 등급, 피드백, 치환·삭제·삽입(S/D/I)을 계산합니다. **점수는 인식된 글자와 정답의 일치도에 기반합니다.** |
| 평가 | 결과·재연습 | 정답·인식 문장, 오류 유형, 녹음 음성, 피드백을 보여주고 다시 연습할 수 있게 합니다. |
| 기록 | DB 저장·학습 이력 | 연습 결과를 `practice_runs`에, 글자별 오류를 `error_items`에 저장하도록 연결돼 있습니다. 사용자는 자신의 과거 기록을 조회할 수 있습니다. |
| 기록 | 분석 대시보드 | 총 연습 횟수, 평균 점수, 학습 문장 수, 오류 유형, 난이도별 결과와 성장 그래프를 보여줍니다. |
| 관리자 | 로그인·운영 현황 | 별도 관리자 비밀번호로 진입해 등록 회원 수, 누적 연습 횟수, 평균 점수·STT 처리시간, 회원별 현황을 봅니다. |
| 관리자 | 이용 통계·비교 | 문장·난이도·카테고리별 연습 횟수와 기록의 텍스트 정규화 전후 값을 보여줍니다. |
