## 2. 권리·동의·라이선스

- **본인 또는 허락받은 음성만 사용:** 수집·시연·실험에 사용하는 녹음의 제공자와 동의 여부를 기록합니다. (`consent.txt` 기반 동의 절차 명시)
- **사용 목적과 보관 기간 안내:** 발음 정확도 평가 및 오류 분석 목적으로만 한시적 활용하며, 프로젝트 종료 시 원본 음성은 안전하게 파기합니다. 참여자에게 STT 인식, 평가 결과 저장, 이력 조회 범위 및 삭제 요청 절차를 안내합니다.
- **공개 저장소에 원본 음성 업로드 금지:** 원본 녹음·환경 설정·DB 접속 정보는 공개 저장소에 넣지 않습니다. (`.gitignore` 및 로컬/보안 저장 관리)
- **외부 데이터 출처·라이선스:** 기본 문장 시드는 프로젝트에 포함되어 있습니다. 외부 데이터셋 사용 시 출처, 이용 범위, 라이선스를 명확히 기록합니다.
- **관리자 접근 제어:** 관리자에게 학습자 닉네임과 연습 결과가 표시될 수 있으므로 화면 접근 제어와 DB 접속 권한을 확인하고, 비밀번호나 원본 음성이 노출되지 않도록 유의합니다.

|---|---|----------------------------------------------------------------------------------------------|----------------------------------------------|

| **샘플링레이트** | 모델 요구 규격에 맞춤 (STT 내부 처리, TTS 재생용 파일 16 kHz) | STT는 `src/stt.py` 내부 처리, TTS는 `src/tts.py`의 `librosa.load(..., sr=16000)`             | 16kHz 리샘플링 검증 완료                     |
| **파일 포맷** | 녹음·업로드는 WAV/MP3/M4A 지원; TTS 출력은 표준 PCM 16-bit WAV/PCM 형식 | `app_practice.py` 임시 파일 생성, `src/tts.py`의 `sf.write(..., subtype='PCM_16')`           | 파일 포맷 호환성 및 업로드/재생 테스트 통과  |
| **무음·길이** | 발화 구간 최적화 및 무음 제거 정제 | `normalize.py` 및 오디오 파이프라인 (현재 `src/stt.py`는 기본 `vad_filter` 지정 완료)        | 불필요한 무음 구간 및 최저/최고 길이 검증    |
| **볼륨/RMS** | 일정한 음량 정규화 | 오디오 볼륨 스케일링                                                                         | 보류                                         |
| **잡음 제거** | 로컬 환경에서 VAD 및 노이즈 감소 적용 | `stt_vad_Noise_Reduction.py` 실행 (`run_stt_with_vad()`, `run_stt_with_denoise()` 함수 사용) | `whisper_vad_noise_comparison.csv` 비교 기록 |
| **평가용 텍스트 정규화** | 소문자화, 구두점 제거, 연속 공백 정리; CER 계산 시 공백 제거 | `src/core.py`의 `clean_for_evaluation()`, `calculate_cer_details()`                          | 정답·STT 인식문에 동일 규칙 적용 검증        |



## 4. 학습·검증·평가 분리

- **현재 사용 방식:** NaraTalk은 사전 학습된 `faster-whisper`의 `base` 모델을 CPU `int8`로 로드하여 추론합니다. 제공된 코드에는 자체 음성 데이터로 모델을 재학습하거나 train/validation/test로 분할하는 과정이 없으므로 보류 처리되었습니다.
- **향후 분할 계획:** 추후 음성 모델 학습 및 비교 진행 시 **화자 단위**로 분리하여 동일 화자의 녹음이 평가 세트에 섞이지 않도록 설계합니다.
- **누수 방지 및 시드:** 동일·유사 문장 반복 녹음의 배치와 문장 중복을 기록하며, 향후 분할 스크립트 작성 시 고정 랜덤 시드를 함께 관리합니다.
- **현재 평가 기준:** `src/core.py`를 통해 정답 텍스트와 STT 인식문 간의 WER·CER, S(대치)/D(삭제)/I(삽입) 오류를 계산하고 CER 기반 3단계 등급을 정합니다.

## 5. 재현성 및 산출물 관리

- **실행 명령:**
  - 전처리 스크립트: `python src_tts/normalize.py`
  - Streamlit 앱 실행: `python -m streamlit run app/app.py`
  - *참고:* DB 초기화 시 `src/db.py`의 실행부에서 테이블 생성 및 34문장 시드가 수행되므로, 기존 DB에 미치는 영향을 사전 확인합니다.
- **원본 파일 및 버전 관리:** 수집된 음성은 파일별 식별자, 수집일, 동의 상태, SHA-256 해시값 등을 기록하며 Git 버전 관리 (`feature/audio` 브랜치 커밋)를 추적합니다.
- **생성 산출물 및 경로:**
  - `sentences` (기본 34문장)
  - `practice_runs`, `error_items` (인식 및 평가 결과, 개별 글자 오답)
  - 임시/결과 파일 디렉터리: `src_tts/test_audio/`, `src_tts/result_comparison/`, `src_tts/validation/`, `src_tts/listening_test/`
  - *보안:* DB 접속 정보는 `src/.env`에 분리 보관하며 산출물로 공유하지 않습니다.
